# 晚安小工程车

一个面向 2 岁幼儿的浏览器睡前故事 Demo。主题围绕工程车，体验重点是安静、柔和、可直接静态部署。

## 产品概念

- 适合睡前使用的柔和网页界面，中文文案优先。
- 宝宝可以选择喜欢的小工程车角色。
- 家长可以选择约 `1 分钟 / 3 分钟 / 5 分钟` 的故事长度。
- 页面会生成一篇短句、重复节奏、没有惊吓内容的晚安故事。
- 支持浏览器语音朗读、夜晚氛围切换、白噪音文字提示、收藏故事到本地。

## 功能清单

- 6 个工程车角色选择：小挖掘机、小吊车、小翻斗车、小搅拌车、小压路机、小卡车
- 8 个内置故事模板，内容适合 2 岁幼儿
- 三档故事时长
- 浏览器 `SpeechSynthesis` 朗读，含播放 / 暂停 / 停止
- 本地收藏区，使用 `localStorage`
- 夜晚氛围控制：星星多少、白噪音文字提示
- 纯静态实现，无外部依赖，无构建步骤

## 本地运行

直接打开 `index.html` 就可以使用。

如果想用本地静态服务器测试，也可以在项目目录运行：

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

## 部署

这个项目是 GitHub Pages 友好的，入口文件就是根目录下的 `index.html`。

部署方式：

1. 推送仓库到 GitHub
2. 在仓库设置里打开 GitHub Pages
3. 选择从默认分支的根目录部署
4. 等待 Pages 构建完成后访问站点

也可以部署到任何静态托管平台，例如 Vercel Static、Netlify、Cloudflare Pages、Nginx 静态目录等。

## 文件说明

- `index.html`：完整单页应用，包含 HTML、CSS、JavaScript
- `README.md`：项目说明和部署说明

## 设计原则

- 视觉上偏柔和、圆润、夜晚氛围
- 交互上偏大按钮、低复杂度、适合手机
- 内容上偏短句、重复、温暖、稳定节奏
- 不使用外部图片或音频，保证静态部署简单
